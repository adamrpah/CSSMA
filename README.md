# CRJU 9610: Computational Social Science: Methods and Applications

This repository contains the course materials for Computational Social Science: Methods and Applications. The course is laid out as such:

* `data/` -- data files to support the course instruction
* `docker/` -- supporting files to create a docker image that would allow for the installation of an anaconda python distribution that will work with all required python packages for the course materials.
* `homeworks/` -- homework files to be completed during the course
* `images/` -- images used in course notebooks
* `lessons/` -- folder for all course lessons. Lessons are grouped based on their topical nature and reflect that the course has gone through multiple iterations fo course content.
* `presentations/` -- all presentations given in the course
* `syllabus/` -- all syllabi that the course has had over the years
*  `requirements_conda.txt` --  requirements file for building a local anaconda environment for use with the course
*  `prologue.ipynb` -- the jupyter notebook that serves as the course roadmap
